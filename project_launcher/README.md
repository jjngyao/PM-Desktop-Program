# 项目快速启动工具

一个轻量级的 Windows 桌面工具，用于集中管理和快速启动分散在磁盘上的开发项目。双击列表即可在 IDE 中打开项目，告别手动翻找目录。

## 快速开始

### 方式一：直接运行（需要 Python）

```bash
python main.py
```

### 方式二：打包为独立 EXE（推荐）

双击 `build.bat`，等待构建完成。生成的 `ProjectLauncher.exe` 位于 `dist\` 目录下，可复制到任意位置或桌面直接双击运行，无需安装 Python 或任何依赖。

## 使用说明

### 1. 首次启动

首次运行时，程序会提示你设置项目的**基础目录**（所有项目存放的顶层文件夹，例如 `D:\` 或 `D:\projects`）。

点击窗口左上角的 **⚙ 齿轮图标** 打开设置面板：

| 设置项 | 说明 |
|---|---|
| **Base Directory** | 项目存放的顶层目录，程序会扫描其下的子文件夹 |
| **IDE** | 选择打开项目使用的 IDE（自动检测已安装的 VS Code / Cursor / Windsurf） |
| **Excluded Directories** | 排除不需要显示的目录（默认已排除 node_modules、.git 等） |
| **Sort** | 勾选后按最近修改时间排序，取消则按名称排序 |

### 2. 浏览项目

设置完成后，主窗口会以列表形式展示所有项目：

- 每个项目显示名称、完整路径和最后修改时间
- 绿色圆点表示该项目包含 Git 仓库（`.git` 目录）
- 鼠标悬停时项目行高亮

### 3. 搜索项目

在顶部搜索框中输入关键字，列表会**实时筛选**匹配的项目。

### 4. 启动项目

- **双击** 项目条目 → 在 IDE 中打开该项目
- **右键** 项目条目 → 可选「在文件资源管理器中打开」或「复制路径」

### 5. 刷新列表

按 **F5** 或点击 **↻ 刷新按钮** 重新扫描目录。

## 文件与配置

配置以 JSON 格式存储，存放位置遵循以下优先级：

1. **便携模式**：EXE 同目录下的 `config.json`（适合放入 U 盘）
2. **标准模式**：`%APPDATA%\ProjectLauncher\config.json`

配置内容包括：基础目录、IDE 选择、排除目录、窗口位置等。

## 常见问题

**Q: 双击项目没反应？**
检查设置中的 IDE 是否已正确检测。如未安装任何 IDE，程序会使用文件资源管理器打开目录。

**Q: 项目列表为空？**
确认「Base Directory」设置正确，且该目录下存在子文件夹。

**Q: 如何排除更多目录？**
打开设置面板，在「Excluded Directories」中添加目录名即可。

**Q: 能放在 U 盘里用吗？**
可以。将 `ProjectLauncher.exe` 和 `config.json` 放在同一目录即可实现便携运行。

## 依赖

### 运行

- **Python 3.10+** — 运行时环境
- **Tkinter** — GUI 库（Python 标准库，通常随 Python 一起安装）

> 运行阶段不依赖任何第三方库，仅需 Python 标准库即可。

### 打包（可选）

如果想把项目打包为独立 EXE，需要额外安装 **PyInstaller**：

```bash
pip install -r requirements.txt
```

或直接安装：

```bash
pip install pyinstaller
```

## 技术信息

- **GUI**：Tkinter（Python 标准库）
- **打包**：PyInstaller → 单文件 EXE（约 8–12 MB）
